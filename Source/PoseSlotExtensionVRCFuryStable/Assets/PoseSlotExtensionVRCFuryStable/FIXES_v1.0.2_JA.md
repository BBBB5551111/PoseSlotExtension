# VRCFury Stable v1.0.2 修正内容

- 対象アバターにBuddyWorks Poses Extension `[VRCF]` が無くても、Package同梱Prefabから自動導入します。
- `[MA]` 版しか配置されていない場合も、`[MA]` 原本を編集せず、VRCFury固定経路を構築します。
- 旧PoseSlotExtensionの欠損Parameters／メニュー参照を除去し、現行Stable参照だけへ修復します。
- `SiuSiuUniversal`を用いて、NDMF検証、VRChat公式SDK Build、既存Blueprintへの実アップロードまで成功を確認しました。
